\# Weather API



A simple weather API built with Flask.



\## Features

\- Fetch weather from Open-Meteo API

\- City search

\- In-memory caching

\- Error handling

\- Environment variables



\## Run



pip install -r requirements.txt



python app.py



\## Example



http://127.0.0.1:5001/weather?city=Hyderabad
